(1:00 — ARCHITECTURE)
(show assets/architecture_diagram.png)
Let's look under the hood. When you submit a request, it first hits our security_checkpoint node, which scrubs any PII like social security numbers and blocks malicious prompt injections. If it's safe, the request goes to the Coordinator agent. The Coordinator acts as the project manager, dynamically calling five specialized sub-agents based on your input: the company_agent, website_agent, social_agent, document_agent, and scam_agent. These agents don't just guess—they use a FastMCP server to pull real-world data like domain WHOIS records, SSL certificates, and PDF metadata. Once all the evidence is collected, the risk_assessment agent scores it. If the risk is critical, the workflow hits a Human-in-the-Loop approval gate, physically pausing the execution until a human signs off. Finally, the explainability agent generates a beautiful, transparent report.

(3:00 — SECURITY & MCP)
I want to highlight two massive technical wins here. First, the security checkpoint ensures that user PII never makes it to the LLM and creates a strict audit log. Second, our FastMCP server completely separates the deterministic API calls—like DNS lookups and document hashing—from the non-deterministic agent reasoning.
